## 三、通用使用教程

### 1. 客户端推荐

| 平台 | 推荐客户端 | 说明 |
|------|-----------|------|
| **Windows** | Clash Verge Rev / FlClash / v2rayN | 支持 V2Ray/Trojan/SS 等多协议 |
| **macOS** | Clash Verge Rev / FlClash | 界面友好，功能强大 |
| **Android** | Clash Meta / FlClash / NekoBox | 移动端主流选择 |
| **iOS** | Shadowrocket（小火箭）/ Stash | 需非中国区 Apple ID 下载 |
| **Linux** | Clash Verge Rev / mihomo | 命令行和GUI均有 |

### 2. 通用使用流程

```
注册账号 → 选购套餐 → 支付订单 → 获取订阅链接 → 导入客户端 → 选择节点 → 连接上网
```

**第一步：注册账号**
- 点击对应机场的注册链接
- 填写邮箱和密码
- 部分机场需要邮箱验证码或滑块验证

**第二步：选购套餐**
- 登录后进入「商店」页面
- 根据流量需求和预算选择合适套餐
- 建议先月付或买小套餐试用

**第三步：获取订阅**
- 购买成功后进入「仪表盘」
- 复制「一键订阅」链接
- 或扫描二维码导入移动端

**第四步：导入客户端**
- 打开客户端软件
- 选择「从订阅链接导入」
- 粘贴订阅链接并更新

**第五步：选择节点**
- 在客户端节点列表中选择延迟较低的节点
- 建议选择距离较近的地区（如香港、日本、新加坡）
- 测试连通性后即可使用

### 3. 常见问题

**Q: 订阅链接无法更新？**
A: 检查网络连接，确认订阅链接未过期，尝试更换节点后更新。

**Q: 连接后无法上网？**
A: 检查节点是否在线，尝试切换其他节点，确认客户端配置正确。

**Q: 速度慢？**
A: 尝试切换不同地区的节点，选择晚高峰外的时间段使用，检查本地网络。

**Q: 流媒体无法解锁？**
A: 选择标注有"解锁"或"流媒体"的节点，部分节点可能不支持特定平台。

### 注意事项

1. **先试后买**：建议先购买月付或小套餐试用，确认速度和稳定性后再考虑长期套餐
2. **不退款**：大部分机场（如三毛）明确不支持退款，请谨慎选择
3. **套餐切换**：未用完流量时不要随意切换套餐，可能导致旧套餐失效
4. **保留备份**：建议同时备有2个以上不同机场，以防某一机场临时不可用
5. **关注公告**：定期查看机场公告，了解线路调整、维护等信息
6. **价格变动**：机场价格和套餐可能随时调整，本文档数据为采集时的快照，请以官网最新信息为准
