## 机场是什么

“机场”并不是真正的机场，而是中文网络里对代理订阅服务商的俗称，这个叫法来自早期的 Shadowsocks 社区。平时大家说的翻墙、科学上网、梯子、代理、VPN，落到具体产品形态上，多数就是这里的“机场”加上一个客户端。它的业务模式并不复杂：服务商在海外租用服务器并搭建代理节点，用户按其套餐付费，付费后获得一条订阅链接，把这条链接导入代理客户端，客户端会自动拉取节点列表，之后设备上的网络请求就可以经由这些海外节点中转。所以“买机场”实际上买的是三样东西——可用的节点、一条能自动更新的订阅链接，以及一定额度的流量。

理解机场需要先认识几个常出现的术语。**节点**指一台具体的海外服务器，通常按地区命名，如香港、日本、新加坡、美西。**订阅链接**是客户端自动获取节点配置的地址，等同于账号凭证，泄露后别人可以直接消耗你的流量。**面板**指机场的用户后台，常见的是 V2board 及其衍生系统，少数机场使用自研面板，差别主要在界面与调度实现。**协议**指客户端与节点之间的传输方式，常见的有 Shadowsocks、Trojan、VMess、VLESS，以及近年较新的 Hysteria 2，后者基于 UDP，在丢包严重的网络环境下表现更好。**线路**是决定体验的关键：直连成本最低但晚高峰最容易拥堵，公网中转在境内加一段加密隧道，稳定性居中，IEPL、IPLC 这类企业专线质量最好但价格也最高。**流量**的计费方式分两种，多数机场按月清零，少数机场如本文提到的魔戒按量计费、用完为止。**解锁**指节点能否正常访问 Netflix、Disney+、ChatGPT 等对 IP 敏感的服务，取决于落地 IP 的归属与风控情况，同一机场不同节点的解锁能力往往不一致。

从消费角度看，机场的核心风险不在技术而在服务商本身。这类服务商多为个人或小团队运营，关停、换域名、跑路并不罕见，运营年限与口碑是最直接的参考；同时几乎所有机场都把订阅视为虚拟商品，购买后不支持退款。因此通行的做法是先买最小档或月付试速度，再考虑长期套餐，同时保留两家以上机场作为主力与备用，避免单一服务出现问题时完全失去连接。

## 三毛机场

在六家机场中，三毛的价格下限最低。官网宣传为“高速梯子月付不到 3 毛，年费最低 3 元”。它的套餐梯度比较细：轻量套餐每月 5GB，年付 3 元；小流量 120GB 年付 12.99 元；中流量 200GB 年付 19.99 元；中大流量 500GB 年付 29.99 元；大流量 1200GB 月付 5 元或年付 60 元；超大流量 3000GB 月付 8 元或年付 96 元。此外还有一个不限时套餐，一次性 25.99 元给 1000GB，用完为止。各档位官方均标注支持 ChatGPT 与流媒体解锁、不限制设备数量。

该机场使用 V2board 面板，注册时需通过 Cloudflare Turnstile 验证。节点全部位于海外，没有国内机房，所有套餐共用同一节点池，因此不同价位之间主要是流量额度的区别，而非线路等级的区别。

使用前有几点需要了解：虚拟商品购买后不支持退款；当前套餐未用完时切换套餐会导致旧套餐立即失效且不退款；付款后应等待系统处理（通常十分钟内开通），不要提前取消订单；官方仅对教程中列出的客户端提供技术支持。另外，由于线路均走海外，中国大陆访问在高峰时段出现卡顿或降速属于出口带宽与路由策略导致的常见现象。

## 良心云

良心云的定位是在低价区间里强调线路质量。官网宣传语为“最良心的高性价比机场，四网高可靠性互联，极致的响应速度”，主要卖点包括电信、联通、移动、广电四大运营商的互联优化、军工级 TLS 1.3 加密、流媒体全面解锁以及全球节点覆盖。与多数机场不同，它采用自研的 Vue 前端面板和自研后端，而非通用的 V2board。

访问官网时需要通过 Cloudflare 与滑块验证，注册流程与常见机场一致。它的套餐价格随活动浮动较大，没有稳定的长期价格快照，建议注册后直接查看商店内的实时报价再决定。

## 魔戒机场

魔戒的产品逻辑与上面两家不同，它不卖包月，而是按量计费：一次性购买流量包，消费完为止，流量不按月清零、也没有时间限制。这种模式对用量少或不固定的用户成本优势明显——官方与公开测评显示，其基础流量包为 130GB 售价 14.9 元，折合每 GB 约 0.11 元；另有约 1 元起的尝鲜小包、420GB 约 42 元、750GB 约 69 元、1300GB 约 118 元等档位，全系不限制同时在线设备数量。

魔戒是圈内运营时间较长的老机场，公开资料显示已稳定运营五年以上。线路结构为国内公网多线 BGP 前置接入加公网加密中转，落地节点覆盖香港、台湾、日本、新加坡、美西洛杉矶及欧洲，协议支持 Shadowsocks、Trojan、VMess 以及抗丢包能力较强的 Hysteria 2。公开测评的结论是：日常时段吞吐充足，Hysteria 2 节点在晚高峰丢包环境下表现好于传统 TCP 协议，但公网中转链路在高并发时段的抖动仍不及物理专线。

因此更合理的用法是把它当作低频主力或应急备用，比如在客户端策略组里作为主机场故障时的兜底线路，而不是唯一的高强度主力。另外其官网采用 IP 直连形式，若某天无法打开，一般意味着地址已更换，需要从公告渠道获取新地址。

## 客户端选择

科学上网的体验一半取决于机场，一半取决于客户端。桌面端推荐 Clash Verge Rev，Windows、macOS、Linux 通用，界面清晰；也可选择 FlClash、v2rayN。Android 端常用 FlClash、Clash Meta、NekoBox。iOS 端为 Shadowrocket（小火箭）或 Stash，需使用非中国区 Apple ID 下载。有软路由或 NAS 的用户可以在网关层部署 mihomo，让家里的电视、游戏机等设备一起走代理，实现全屋翻墙共享。

## 通用使用流程

各机场流程基本一致：注册账号、购买套餐、复制订阅链接、导入客户端、选择节点连接。注册时按页面提示完成滑块、拼图或邮箱验证；购买环节建议先选最小档或月付套餐试用，确认速度与稳定性后再考虑长期套餐；订阅链接在仪表盘的“一键订阅”处获取，导入后点击更新即可生成节点列表；节点选择上优先考虑香港、日本、新加坡等距离较近的地区，并通过客户端测延迟后再确定。整套流程走完，设备就处于代理状态，浏览器可以直接访问境外网站。

## 常见问题

订阅更新失败或节点列表为空，通常是官网无法访问或链接失效，可先确认官网连通性，再重新复制订阅链接导入。连接成功但无法上网，优先检查节点是否可用、客户端系统代理或 TUN 模式是否开启、流量是否已用尽。速度偏慢时先更换节点与地区，其次考虑是否为晚间高峰时段，最后排查本地宽带状况。流媒体与 AI 服务无法访问时，应切换到标注解锁或专用的节点，同一机场不同节点的解锁能力并不一致。

## 常见搜索问题

**机场和 VPN 有什么区别？** 两者目的接近，都是为了让设备访问境外网络，但实现方式不同。传统 VPN 通常整机流量走同一条隧道，协议固定，容易被识别与限速；机场则基于 Shadowsocks、Trojan、VMess、VLESS、Hysteria 2 等协议，节点多、可按地区切换，并且支持客户端分流规则，只让需要的流量走代理，因此在国内环境下通常比大众 VPN 更稳定、体验更灵活。

**免费机场能用吗？** 免费节点一般存在速度慢、节点少、频繁掉线、隐私不明等问题，部分还会记录或出售用户流量信息。可以用作临时应急或测试客户端的连通性，但不建议长期依赖，更不要在上面登录重要账号。

**机场会跑路吗？怎么判断？** 会，这是这类服务最常见的风险。判断依据主要是运营年限、是否有稳定的公告渠道、用户口碑、是否长期做活动清库存、订阅价格是否明显低于成本线。对新开且只在短期打超低价年付的机场，建议只买最小套餐。

**哪个机场最便宜？** 本文六家中，三毛的入门门槛最低，轻量套餐年付 3 元、120GB 年付 12.99 元；如果按实际用量折算，魔戒的一次性流量包（130GB 约 14.9 元）对低频用户更划算，因为流量不过期、不会月底清零。

**包月套餐和一次性流量包怎么选？** 每天都要用、流量消耗稳定，选包月或年付；一个月只用几 GB 到十几 GB、用网时间不固定，选按量计费的一次性流量包，能避免每月为用不完的流量付费。

**手机怎么科学上网？苹果手机用什么客户端？** Android 常用 FlClash、Clash Meta、NekoBox；iOS 常用 Shadowrocket（小火箭）或 Stash，需要非中国区 Apple ID 才能下载。装好后把机场的订阅链接粘贴进去，更新订阅、选择节点并开启代理即可。

**Clash、V2Ray 的订阅链接怎么导入？** 在机场仪表盘复制“一键订阅”链接，打开客户端选择“从链接导入”或“添加订阅”，粘贴后更新，客户端会自动生成节点列表。若导入后节点为空，多半是订阅链接失效或官网当前无法访问。

**机场节点应该怎么选？** 优先选距离近的地区（香港、日本、新加坡、台湾），延迟通常更低；看视频选标注流媒体或高带宽的节点；访问 ChatGPT、Claude 等 AI 服务选标注 AI 或原生 IP 的节点；晚高峰卡顿时优先切换到 Hysteria 2 或中转类节点。

## 几点建议

第一，首次购买尽量选最小档或月付，多数机场对虚拟商品不支持退款。第二，建议同时保留两家以上机场，主力与备用分开，避免单一服务维护时完全失去连接。第三，尽量避免只在晚八点到十一点的高峰时段做速度判断。第四，订阅链接等同于账号凭证，不宜外传。第五，低频用户优先考虑按量计费产品，包月套餐在流量清零机制下对低频用户的实际成本更高。第六，本文的排序依据是价格下限与综合体验，并不代表这几家适合所有人；实际选购时按自己的用量、常用线路和预算对号入座即可。
