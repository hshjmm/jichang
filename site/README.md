## 机场是什么（翻墙、梯子、科学上网）

“机场”并不是真正的机场，而是中文网络里对代理订阅服务商的俗称，这个叫法来自早期的 Shadowsocks 社区。平时大家说的翻墙、科学上网、梯子、代理、VPN，落到具体产品形态上，多数就是这里的“机场”加上一个客户端。它的业务模式并不复杂：服务商在海外租用服务器并搭建代理节点，用户按其套餐付费，付费后获得一条订阅链接，把这条链接导入代理客户端，客户端会自动拉取节点列表，之后设备上的网络请求就可以经由这些海外节点中转。所以“买机场”实际上买的是三样东西——可用的节点、一条能自动更新的订阅链接，以及一定额度的流量。

理解机场需要先认识几个常出现的术语。**节点**指一台具体的海外服务器，通常按地区命名，如香港、日本、新加坡、美西。**订阅链接**是客户端自动获取节点配置的地址，等同于账号凭证，泄露后别人可以直接消耗你的流量。**协议**指客户端与节点之间的传输方式，常见的有 Shadowsocks、Trojan、VMess、VLESS，以及近年较新的 Hysteria 2，后者基于 UDP，在丢包严重的网络环境下表现更好。**线路**是决定体验的关键：直连成本最低但晚高峰最容易拥堵，公网中转在境内加一段加密隧道，稳定性居中，IEPL、IPLC 这类企业专线质量最好但价格也最高。**流量**的计费方式也分几种：按月清零的周期套餐、一次买断用完为止的流量包、以及买断后不过期的永久流量包。**解锁**指节点能否正常访问 Netflix、Disney+、ChatGPT 等对 IP 敏感的服务，取决于落地 IP 的归属与风控情况，同一机场不同节点的解锁能力往往不一致。

从消费角度看，机场的核心风险不在技术而在服务商本身。这类服务商多为个人或小团队运营，关停、换域名、跑路并不罕见，运营年限与口碑是最直接的参考；同时几乎所有机场都把订阅视为虚拟商品，购买后不支持退款。因此通行的做法是先买最小档或月付试速度，再考虑长期套餐，同时保留两家以上机场作为主力与备用，避免单一服务出现问题时完全失去连接。

## 客户端选择（Clash、V2Ray、小火箭）

科学上网的体验一半取决于机场，一半取决于客户端。桌面端推荐 Clash Verge Rev，Windows、macOS、Linux 通用，界面清晰；也可选择 FlClash、v2rayN。Android 端常用 FlClash、Clash Meta、NekoBox。iOS 端为 Shadowrocket（小火箭）或 Stash，需使用非中国区 Apple ID 下载。有软路由或 NAS 的用户可以在网关层部署 mihomo，让家里的电视、游戏机等设备一起走代理，实现全屋翻墙共享。

### 机场自研客户端：什么时候用，什么时候别用

不少机场会自己做个客户端，装上、登录、点连接就能用，不用手动导入订阅。这类客户端有明显的好处：开箱即用，订阅和节点通常内置好了，对自家协议（尤其是 Hysteria 2 这类较新的）适配最到位，节点和分流规则也能自动更新，而且官方客服基本只对自家客户端提供技术支持，出问题更容易定位。

代价也很明确：它只认自家机场，手里有两三个机场就得装两三个客户端；平台覆盖往往不全，常见只有 Windows 和 Android，iOS 可能要 TestFlight、Linux 基本没有；闭源意味着无法审查它做了什么，权限和隐私只能靠信任；功能也不如社区客户端细，规则自定义、脚本分流这些基本没有；最重要的是它跟着机场走，机场一旦关停，客户端也就废了。

所以怎么选很简单：只用一个机场、平时就刷网页看视频，自研客户端最省事；同时用多个机场、需要精细分流或长期稳定，就老老实实用 Clash Verge Rev、FlClash、V2RayN、小火箭这类通用客户端，把各家订阅都导进去统一管理。

## 机场怎么买怎么用（注册到导入客户端）

第一步，注册账号。打开对应机场的官网，填邮箱和密码即可完成注册，国内常用的 QQ、163 邮箱基本都能用。注册环节按页面提示填写就行，不需要自己配置任何东西。

第二步，购买套餐。登录后进入「商店」或「购买订阅」页面挑档位。第一次买建议只选最小档或月付——三毛 3 元一年、素心 2 元体验包、魔戒 1 元 1GB 这种几块钱的档位，试错成本几乎为零。付款方式多为支付宝或站内余额，付款后一般几分钟内自动开通，别着急取消订单。

第三步，复制订阅链接。开通后到「仪表盘」或「我的订阅」页面，找到「一键订阅」「Clash 订阅」之类的按钮，复制那条链接。这条链接等同于你的账号凭证，不要发给别人，也不要发到群里。

第四步，导入客户端。打开 Clash Verge（Windows / macOS / Linux）、V2RayN，或 iOS 上的 Shadowrocket（小火箭），选择「从剪贴板导入」或「添加订阅 / 添加配置」，粘贴链接后点更新，客户端会自动拉取节点列表。

第五步，选节点并测延迟。在节点列表里点一下延迟测试，优先选香港、日本、新加坡、台湾这些距离近的地区；看视频选标注流媒体或高带宽的节点；访问 ChatGPT、Claude 这类 AI 服务选标注 AI 或原生 IP 的节点。晚高峰卡顿时换一个地区的节点往往就好了。

第六步，检查分流规则。默认规则一般是「国内直连、国外走代理」，不建议随手开全局代理，否则国内网站也会绕一圈反而更慢。设置完成后刷新浏览器，能正常打开境外网站就说明配置成功。

另外，每个机场官网基本都有「使用文档」或「使用教程」入口，里面有图文并茂的详细步骤——注册、购买、导入订阅、换节点都带截图。第一次用建议先翻一遍，比看任何第三方教程都准，也不会被过时的写法带偏。

> [!WARNING]
> **虚拟商品基本都不支持退款**，这是最容易吃亏的地方：下单前先确认套餐内容和流量额度；套餐没用完时切换档位，旧套餐往往直接作废且不退款；付款后别急着取消订单，等系统开通。另外订阅链接等同于账号凭证，泄露出去别人能直接消耗你的流量，别发群里、别贴论坛。

## 常见问题（连不上、速度慢、订阅失效）

订阅更新失败或节点列表为空，通常是官网无法访问或链接失效，可先确认官网连通性，再重新复制订阅链接导入。连接成功但无法上网，优先检查节点是否可用、客户端系统代理或 TUN 模式是否开启、流量是否已用尽。速度偏慢时先更换节点与地区，其次考虑是否为晚间高峰时段，最后排查本地宽带状况。流媒体与 AI 服务无法访问时，应切换到标注解锁或专用的节点，同一机场不同节点的解锁能力并不一致。

## 常见搜索问题

**机场和 VPN 有什么区别？** 两者目的接近，都是为了让设备访问境外网络，但实现方式不同。传统 VPN 通常整机流量走同一条隧道，协议固定，容易被识别与限速；机场则基于 Shadowsocks、Trojan、VMess、VLESS、Hysteria 2 等协议，节点多、可按地区切换，并且支持客户端分流规则，只让需要的流量走代理，因此在国内环境下通常比大众 VPN 更稳定、体验更灵活。

**免费机场能用吗？** 免费节点一般存在速度慢、节点少、频繁掉线、隐私不明等问题，部分还会记录或出售用户流量信息。可以用作临时应急或测试客户端的连通性，但不建议长期依赖，更不要在上面登录重要账号。付费机场附带的免费档也一样（比如星链的永久免费档），官方自己都标了“有一定程度风控”，拿来应急可以，当主力迟早难受。

**机场会跑路吗？怎么判断？** 会，这是这类服务最常见的风险。判断依据主要是运营年限、是否有稳定的公告渠道、用户口碑、是否长期做活动清库存、订阅价格是否明显低于成本线。对新开且只在短期打超低价年付的机场，建议只买最小套餐。

**邀请制机场是什么？** 邀请制就是机场不开放公开注册，必须拿邀请码才能开号，目的通常是控制用户数量、避免线路超售，本文的素心就属于这一类。邀请码一般有使用名额和时效，别人给的码尽早用。

**哪个机场最便宜？** 单次花钱最少的是魔戒，1 元就能拿个 1GB 体验包；如果要完全不花钱，星链有永久免费档，只做轻量用途的话够用；按单月流量单价看，良心云最低，100GB 每月 2 元；按年付总价看，三毛最低，5GB 每月一年只要 3 元，Sakuracat 的微量档 3.8 元、精靈學院的 Iron 档 8 元属于中间偏低的常规价位；按“买一次能用很久”的角度看，魔戒同样划算，19.9 元拿 130GB 且不过期。按实际用量换算，低频用户往往魔戒更省，高频用户则是良心云更省。

**包月套餐和一次性流量包怎么选？** 每天都要用、流量消耗稳定，选包月或年付；一个月只用几 GB 到十几 GB、用网时间不固定，选按量计费或一次性流量包，能避免每月为用不完的流量付费。

**手机怎么科学上网？苹果手机用什么客户端？** Android 常用 FlClash、Clash Meta、NekoBox；iOS 常用 Shadowrocket（小火箭）或 Stash，需要非中国区 Apple ID 才能下载。装好后把机场的订阅链接粘贴进去，更新订阅、选择节点并开启代理即可。

**Clash、V2Ray 的订阅链接怎么导入？** 在机场仪表盘复制“一键订阅”链接，打开客户端选择“从链接导入”或“添加订阅”，粘贴后更新，客户端会自动生成节点列表。若导入后节点为空，多半是订阅链接失效或官网当前无法访问。

**机场节点应该怎么选？** 优先选距离近的地区（香港、日本、新加坡、台湾），延迟通常更低；看视频选标注流媒体或高带宽的节点；访问 ChatGPT、Claude 等 AI 服务选标注 AI 或原生 IP 的节点；晚高峰卡顿时优先切换到专线或中转类节点。

**流量套餐里的“倍率”是什么意思？** 部分机场按倍率计费，1.0 倍率表示用 1GB 扣 1GB，0.1 倍率则是用 10GB 只扣 1GB，3x 节点就是扣 3 倍。良心云标注全节点 1.0 倍率、无高倍线路；精靈學院则明确写了普通线路 1 倍、标 3x 的高速节点按 3 倍扣流量，用这类高速节点时要留意流量消耗。

## 几点建议

第一，首次购买尽量选最小档或月付，多数机场对虚拟商品不支持退款。第二，建议同时保留两家以上机场，主力与备用分开，避免单一服务维护时完全失去连接。第三，尽量避免只在晚八点到十一点的高峰时段做速度判断。第四，订阅链接等同于账号凭证，不宜外传。第五，低频用户优先考虑按量计费产品，包月套餐在流量清零机制下对低频用户的实际成本更高。第六，本文排序是综合价格、产品线覆盖和适用人群给出的主观顺序，入门价只是参考之一；实际选购请结合用量、常用线路和预算，按文中各表逐项核对。
